1. What is an ARX Cipher?

SPECK is a lightweight ARX cipher built using only three basic CPU instructions:

➕

Modular Addition

Provides non-linear mixing and carry bit propagation mod $2^{32}$.

🔄

Circular Rotation

Provides linear diffusion ($\text{ROR}_8$ and $\text{ROL}_3$) across 32-bit words.

⊕

Bitwise XOR

Injects round subkeys $k_i$ and combines state variables linearly.

Viva Talking Point: Unlike AES, SPECK uses zero S-Boxes or lookup tables, protecting against cache-timing side-channel attacks and running efficiently on constrained UDP packet processors.

2. Authenticated 21-Byte Wire Protocol Layout

1 Byte Tier ID 0x01 = LOW, 0x02 = HIGH
8 Bytes SPECK Ciphertext Encrypted Payload (T=12/27)
4 Bytes Sequence Number Big-Endian (>I)
8 Bytes Truncated MAC HMAC-SHA256 (64 bits)
Verify-Then-Decrypt Invariant: The receiver verifies the MAC before attempting SPECK decryption. If MAC is invalid, decryption is skipped completely.
